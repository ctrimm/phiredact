Measured, not marketed.

phiredact is a purpose-built redaction instrument: an 11 MB token-classification model and a checksum-gated rules engine, running entirely on-device. This page is its data sheet. Every figure comes from the public benchmark harness in the SDK repository; configurations and corpus sizes are stated beside each result.

Methods & limits

How the numbers were made
Methods

Benchmarks were run with interleaved language order over shared, seeded corpora, so no implementation benefits from cache warmth or ordering. Corpus hashes and per-stage output digests are published in the repository (PERFORMANCE.md), and every figure on this page can be re-derived from the harness that ships with the SDK.

The golden set is a 164-note corpus of synthetic clinical and case text with hand-checked spans; the full-value recall figure counts a detection only when the entire value — name, number, date — is captured. The clinical corpus behind the strict F1 figures is a separate, larger set of clinical notes scored span-for-span against a single annotation standard, with the same harness driving both systems.

Limits. Small-note figures describe micro-text — notes of a few hundred characters — and are labeled as such wherever they appear; Table 2 exists precisely so the per-note numbers are never mistaken for document-scale costs. The corpora are English. phiredact detects 32 entity types in clinical and case text; it is not a general-purpose anonymization framework, and nothing on this page should be read as a claim beyond the corpora described.

Where the generalist wins

Fair play, stated plainly
01

Breadth of entities

Presidio ships recognizers for a wider world — more identifier families, more countries, more formats. phiredact covers 32 types in one domain and declines the rest.

Presidio
02

Languages

Presidio works across many languages. phiredact is English-first, tuned on English clinical and case text; other languages are not claimed.

Presidio
03

Images & structured data

As a framework, Presidio extends to images, DICOM and tabular pipelines. phiredact’s image support lives in the Mac application, and its SDKs are text-only.

Presidio
04

Configuration matters

The honest finding of the head-to-head: roughly two-thirds of the gap between the default Presidio row and phiredact was configuration, not architecture — a de-identifier model plus threshold tuning recovers most of it, at ~573 ms per note instead of 37.8. Default configurations are what most deployments actually run, which is why both rows are printed.

Both, tuned
The claim, in one sentence. On English clinical and case text, measured on a shared corpus with a shared harness, a specialist 11 MB model that runs on-device outperforms the default configuration of the general framework — and the tuned framework’s numbers are printed above, next to ours.
