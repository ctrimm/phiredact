First

Built to run in this tab

The model is built to execute on your machine, in the browser. There is no redaction endpoint to send text to — redaction works with the network cable pulled.

Second

It will download once

The 11 MB model is fetched a single time and cached by your browser. After that, every redaction is local arithmetic, at the speeds in the tables.

Third

Closing the tab ends it

Your text will live only in this page’s memory. Close the tab and it is gone — there is no account, no history, and nothing on a server to delete.

phi-redact is a detection tool that assists de-identification. It is not a certification of HIPAA compliance, and no output should be treated as expert-certified de-identified data.
